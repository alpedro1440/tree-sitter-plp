# Fixture pengujian Tugas 6

- `app.py` berisi komentar TODO dan satu fungsi panjang (lebih dari 30 baris).
- `broken.py` sengaja memiliki tanda `:` yang hilang agar parser melaporkan `ERROR` atau `MISSING`.

Folder ini adalah fixture lokal untuk uji awal. Sesuai instruksi tugas, setelah fitur berjalan,
jalankan juga `cek.py` pada satu repositori Python nyata (misalnya repositori proyek kuliah
atau repositori open source kecil), lalu cocokkan minimal dua file secara manual.
